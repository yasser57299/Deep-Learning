# ☕ Tiny AI Coffee Doctor

**Efficient Deep Learning for Coffee Leaf Disease Classification and Rust Severity Assessment**

## Project Overview
Tiny AI Coffee Doctor is a university deep learning research project designed to classify coffee leaf diseases while investigating the trade-off between model accuracy and computational efficiency.

## Planned Features
- Coffee leaf image verification.
- Classification of five conditions: Healthy, Coffee Rust, Cercospora, Phoma, and Leaf Miner.
- Coffee Rust severity estimation.
- Image-upload interface for disease prediction.

## Research Approach
We plan to compare three models:

- **M0:** MobileNetV3-Small (baseline).
- **M1:** MobileNetV3-Small with CBAM Attention.
- **M2:** M1 optimized using INT8 Quantization.

We will evaluate accuracy, F1-score, parameter count, model size, and inference latency.
